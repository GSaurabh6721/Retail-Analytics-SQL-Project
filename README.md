# 📊 Retail Analytics SQL Project

**Tools:** SQL Server, SSMS, Power BI

This project analyzes **Sales, Customers, Finance, and Operations datasets** using SQL to answer real business questions and generate actionable insights. It’s designed to showcase **data modeling, cross-functional analysis, and business intelligence skills**.

---

## 🚀 Project Highlights

### **1️⃣ Sales Analytics**
- Monthly revenue & profit trends  
- Region-wise revenue and profit  
- Category-level margins  
- Top customers by revenue and profit  

### **2️⃣ Finance Analytics**
- Revenue, COGS, Operating Expenses, Net Profit  
- YoY Revenue Growth  
- Margin trends and expense ratio  

### **3️⃣ Operations Analytics**
- SLA performance per category  
- Average resolution time by priority  
- Agent performance analysis  
- Ticket volume trends  

### **4️⃣ Cross-Functional Insights**
- Impact of SLA breaches on monthly revenue  
- High-margin categories vs operational efficiency  
- Customer profitability vs regional sales  
- Operational bottlenecks affecting financial performance  

---

## 📂 SQL Scripts

- `01_sales_analysis.sql` → Monthly trends, category & region sales  
- `02_customer_analysis.sql` → Customer profitability & lifetime value  
- `03_finance_analysis.sql` → Financial KPIs, margin, YoY growth  
- `04_operations_analysis.sql` → SLA, agent KPIs, resolution hours  
- `05_cross_functional_insights.sql` → Combined analysis across datasets  

---

## 📈 How to Use

1. Import CSV datasets from `/datasets` into **SQL Server / SSMS**  
2. Run each SQL script from the `/sql` folder in order  
3. Export results to Excel or Power BI for dashboards (optional)
